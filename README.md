# 拆包助手

一个 Windows 自动多层解压工具。把压缩包放进去，添加可能用到的密码，程序会逐层解压，直到得到最终文件。

当前版本：**0.3.3 预览版**。

## 下载和使用

1. 打开 [下载页面](https://github.com/VanishQAQ/unpack-assistant/releases/latest)，下载 **unpack-assistant-0.3.3-windows-x64.zip**。
2. 解开下载的 ZIP，运行里面的 **拆包助手.exe**，无需安装。
3. 添加需要处理的压缩包，输入候选密码，选择输出目录。
4. 点击 **开始解压**。完成后，在 **设置 → 打开结果** 查看文件。

需要 **Windows 64 位、.NET Framework 4.8**，并安装以下任意一种解压软件：

| 解压软件 | 在“设置 → 高级选项”中选择 | 支持格式 |
| --- | --- | --- |
| [Bandizip](https://www.bandisoft.com/bandizip/) | `bz.exe` | ZIP、7z、RAR |
| [7-Zip](https://www.7-zip.org/) | `7z.exe` | ZIP、7z、RAR |
| [WinRAR](https://www.rarlab.com/) | `WinRAR.exe` 或 `Rar.exe` | 仅 RAR |

本工具调用外部解压软件，不包含这些软件。WinRAR 的命令行程序只支持 RAR；需要处理混合格式时，请选择 Bandizip 或 7-Zip。

## 能做什么

- **自动多层解压**：压缩包里面还有压缩包时，继续处理下一层。
- **自动识别分卷**：支持常见的 7z、ZIP、RAR 分卷，外层解开后出现分卷也能继续。
- **尝试候选密码**：支持中文密码，不同层可以使用不同密码。
- **记住设置**：密码加密保存在当前 Windows 用户账户中，输出目录和选项也会保存。
- **恢复任务**：关闭软件或中途取消后，可以载入任务记录继续处理。
- **清理中间文件**：任务全部成功后，可在“设置 → 结果管理”检查并清理，保留最终结果。

## 分卷怎么放？

把同一组的所有分卷放在**同一个文件夹**，保留原来的名称。

可以全选所有分卷一起添加，也可以只添加其中一卷，程序会自动找到同组文件。缺卷时需要先补齐。

## “恢复任务”怎么用？

点击 **恢复任务**，选择上次输出目录里的 **任务状态.json**，必要时补充密码，再点击 **继续**。

请保留原压缩包和完整的任务文件夹。已完成的层会先校验再复用；中途打断的那一层通常需要重新解压。

## 使用前了解一下

- 这是预览版，请先用可信文件测试。原压缩包不会因为正常解压或结果清理而被删除。
- **0.3.3 不包含病毒扫描功能**，不要把“解压成功”理解为文件安全。
- 多个任务按顺序处理，目前不是同时解压。
- ZIP64 暂不支持；并非所有压缩算法和旧版本都已验证。
- 密码保存依赖当前 Windows 用户，不能直接复制到另一台电脑使用。
- 遇到问题时，请提供错误提示、压缩格式和软件版本。不要在公开反馈中上传私人文件或密码。

## 从源码构建

在 Windows PowerShell 中进入项目目录，运行：

```powershell
.\build.ps1
```

输出位于 `便携版-0.3.3`。使用系统自带的 .NET Framework C# 编译器，无需 NuGet。测试脚本位于 `tests`，部分测试需要安装对应解压软件。
